# Fuentes de los documentos

Las fuentes que la vista previa usa para imitar el PDF. Son las mismas que usa el motor
LaTeX, tomadas de su distribución (TeX Live, a través del bundle de Tectonic) y
reempaquetadas de OpenType a WOFF2 sin cambiar ningún glifo ni tabla.

| TeX Gyre Pagella | `texgyrepagella-*.woff2` | GUST e-foundry    | GUST Font License                |
| TeX Gyre Termes  | `texgyretermes-*.woff2`  | GUST e-foundry    | GUST Font License                |
