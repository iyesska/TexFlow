# Estilos de cita

Estilos CSL que TexFlow ofrece además del predeterminado de Pandoc (Chicago, autor y
año), sin modificar:

| Archivo    | Estilo                 |
| ---------- | ---------------------- |
| `apa.csl`  | APA Style, 7.ª edición |
| `ieee.csl` | IEEE                   |

Proceden del repositorio de estilos del proyecto Citation Style Language
(<https://github.com/citation-style-language/styles>) y se distribuyen bajo la licencia
Creative Commons Attribution-ShareAlike 3.0
(<https://creativecommons.org/licenses/by-sa/3.0/>). Sus autores figuran en el bloque
`<info>` de cada archivo.
