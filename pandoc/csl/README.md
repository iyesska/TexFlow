# Estilos de cita

Estilos CSL que TexFlow ofrece además del predeterminado de Pandoc (Chicago, autor y
año), sin modificar:

| Archivo         | Estilo                                  | Archivo de origen                 |
| --------------- | --------------------------------------- | --------------------------------- |
| `apa.csl`       | APA Style, 7.ª edición                  | `apa.csl`                         |
| `harvard.csl`   | Cite Them Right, 12.ª edición (Harvard) | `harvard-cite-them-right.csl`     |
| `iso-690.csl`   | ISO 690 (autor y año, español)          | `iso690-author-date-es.csl`       |
| `mla.csl`       | MLA Handbook, 9.ª edición               | `modern-language-association.csl` |
| `ieee.csl`      | IEEE                                    | `ieee.csl`                        |
| `vancouver.csl` | Elsevier, NLM/Vancouver (numérico)      | `elsevier-vancouver.csl`          |

Proceden del repositorio de estilos del proyecto Citation Style Language
(<https://github.com/citation-style-language/styles>) y se distribuyen bajo la licencia
Creative Commons Attribution-ShareAlike 3.0
(<https://creativecommons.org/licenses/by-sa/3.0/>). Sus autores figuran en el bloque
`<info>` de cada archivo.
